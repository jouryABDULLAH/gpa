# 📱 Manartik — Student Smart Assistant

Manartik is a mobile application that brings together essential academic tools and services for Qassim University students.  
It helps students find reliable information, navigate campus, track important academic dates, and access key services in one place.

---

## 🚀 Features

##### 🔹 FAQs Assistant (Namik)
A simple question–answer assistant that provides quick responses to common academic questions.  
- Predefined answers  
- Academic service information  
- Advisor and faculty contact access  
  
##### 🔹 Interactive Map
A built-in campus map to help users find buildings and services easily.  
- Search by building name or number  
- View entrances and exits  
- Save locations for quick access  

##### 🔹 Academic Dashboard
A structured view of important academic dates and deadlines.  
- Exam periods  
- Add/withdraw dates  
- GPA calculation times  
- Event notifications  

##### 🔹 Academic Services
Tools and resources students often need:  
- GPA Calculator (semester & cumulative)  
- University Rules & Regulations  
- Student Plan Guide + statistics  
- Program Overview  
- Email contact for academic advisor  

##### 🔹 Digital Student ID
A secure, always-accessible digital version of the student’s university ID card.
